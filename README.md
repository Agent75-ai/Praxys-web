# PRAXYS Web Template

Sitio estático bilingüe ES/EN con estética de montaña, arquitectura de servicios según el póster y panel Admin dinámico.

## Archivos principales
- `index.html`
- `styles.css`
- `main.js`
- `data.json`
- `config.js`
- `assets/logo.svg`
- `assets/hero-mountains.svg`
- `.nojekyll`

## Admin
Usuario: `praxys`
Contraseña: `Praxys2026!`

En GitHub Pages los cambios se guardan en LocalStorage del navegador. Para publicar cambios permanentes, usar `Descargar data.json` y reemplazar el archivo en el repositorio.

## Publicación en GitHub Pages
Subir todos los archivos descomprimidos a la raíz del repositorio. Activar Pages desde `Settings > Pages > Deploy from branch > main / root`.
